Questions

Is it safe to open? It is not from the App Store.
It is signed with an Apple Developer ID and notarised by Apple, so it opens with a normal double-click and no warning. Notarising means Apple has scanned the build; it does not mean Apple endorses it.
Desktop, Documents and Downloads look empty.
Those folders are protected by macOS and need Full Disk Access. Soquel offers to set it up on the first launch, and the same window is under Soquel → Set Up Permissions… A file manager cannot grant itself that, and neither can anything else: the list is protected by System Integrity Protection precisely so no program can add itself to it.
Can Soquel replace Finder?
Not entirely, and no application can. macOS keeps folders for Finder — the call to reassign them is refused. Disks can be reassigned, so double-clicking one opens it here, and anything can be opened in Soquel through Open With.
Does it send anything anywhere?
Not unless you switch one thing on. Search by meaning runs on the language model macOS already ships, on your own machine. There is no account and no telemetry, ever. The one exception is opt-in and off by default: Settings → Updates will ask github.com once a day for the latest release tag and compare it with your build. It sends nothing about you or your machine, and it never downloads or installs anything — it tells you, and the button opens the release page.
Where does it keep my settings?
Three readable JSON files in ~/Library/Application Support/Soquel/: settings (the sidebar included), colours and saved layouts. Edit one in another editor while Soquel is running and the window redraws. Deleting the folder resets everything.
Is it really free?
Yes.
Where do I ask a question or report something?
Two places, pick whichever fits. soquel.hamlet.so is a forum — plain questions, "how do I", "this is behaving oddly", ideas. No GitHub account needed. GitHub issues is for bug reports with steps to reproduce, and feature requests you want tracked against the code.

Changelog

1.5.0

26 Aug 2026 notes
  • Clean This Folder ⌃⌘L, a beta you turn on in Settings › Clean. Reads one folder and suggests where things should go, as moves you tick. Nothing moves until you say so, and the whole clean undoes as one step.
  • Ask whichever service you like, or none: Ollama, LM Studio and llama.cpp run on your own machine and need no key, and Soquel finds the one you already have running. OpenRouter, Anthropic, OpenAI, GLM, DeepSeek, Groq and Together are a click each, or type in any address that speaks either format.
  • The only feature that sends the contents of files anywhere, so: hidden files are not read, files whose names suggest a secret are never opened, anything shaped like a key or a password is removed first, and a button prints the exact text before it is sent. Your files on disk are never altered by any of that.
  • Mark a folder as global and things can be filed into it from anywhere. Write a sentence about what a folder is for and Soquel is told it. A plan may not move a file anywhere else.

1.4.0

24 Aug 2026 notes
  • Launch Soquel from Terminal. Settings › General installs the soquel command; run it on its own or give it one or more folders to open.
  • The installer puts the command in /usr/local/bin, asks for administrator approval only when needed, and asks before replacing a file already using that name.

1.3.0

21 Aug 2026 notes
  • Update channels. The middle number is a finished release, the last one is a nightly, so 1.3.0 is finished work and 1.3.1 would be the day's. Settings › Updates picks which you follow.
  • Soquel can install an update itself — it checks the download is signed by the developer before replacing anything, and refuses outright if it is not. Off until you turn it on.
  • A faulty-build notice. If the version you are running has been withdrawn, Soquel says what breaks and offers one click to the fix and one back to the last good version.
  • Settings › Default App. Finder starts, Soquel takes over, Finder quits — covering the Dock's Finder icon and Reveal in Finder. Also mounted disks, and hiding the desktop icons. One button gives all of it back.
  • The Git column explains itself. Hovering a badge says what Git thinks and what would change it; the column header carries the whole legend.

1.1.1

19 Aug 2026 notes
  • Fixed: a branch whose name begins with a dash was passed to git as an option. git diff --output=<file> writes over that file, so Diff with Current could empty one of your files with one click. This withdrew 1.1.0.
  • Fixed: the diff panel dropped every blank line and numbered every line after one too low.
  • Fixed: parsing a patch was quadratic and ran on the main thread — 16,000 lines froze the window for 8.3 seconds. It is linear now, and off the main thread.
  • Fixed: opening a .diff had no size limit. It refuses over 8 MB, as comparing two files already did.
  • Fixed: extracting one entry of an archive could reveal an unrelated file outside the extraction folder.
  • New: a faulty-build notice. If the version you are running has been withdrawn, Soquel says so and offers one click to install the fix and one to go back to the last good version. Both check the signature first. Settings › Updates turns it off.

1.1.0 — withdrawn

18 Aug 2026 removed

Withdrawn — do not use. In the Branches panel, Diff with Current on a branch whose name begins with a dash can empty one of your files. Git reads the name as an option rather than a branch. Use 1.1.1. This release has been removed and can no longer be downloaded.

  • Compare two files ⌥⌘D. A unified diff with both sets of line numbers. A .diff or .patch opens as a diff instead of grey text.
  • Branches ⇧⌘B. Every local branch with ahead and behind counts, and a diff against the one you are on. Switching branches is a beta setting, off by default — with it on a switch is refused while there are uncommitted changes rather than stashing them for you.
  • Renumber a batch that is already numbered. Close a gap, start somewhere else, or insert in the middle, keeping the rest of every name.
  • Recents ⇧⌘Y. What you opened, moved, renamed and trashed. Recording costs 2.2 microseconds and the file is written on a timer, not per action.
