Search by meaning ⌃⌘F

Ask for "financial results from the German branch" and find the file that says "the Berlin office reported strong quarterly revenue". A query across a thousand passages takes under a millisecond, and the model is the one already on your Mac.

Disk map ⇧⌘U

Rings sized by what is actually on disk. Hard links counted once, symlinks not followed, and the slivers too thin to draw added together rather than dropped, so a ring always totals its parent.

Folder tree ⇧⌘T

The whole hierarchy in the sidebar, loaded a level at a time, opening itself down to whatever the active pane is showing.

Every shortcut is yours

Rebind any command by pressing the keys you want, with clashes caught as you type. There is a vi-style preset if you want j k h l, and it stays out of text fields.

Finding things

Search panel ⌘F
Name or contents; contains, regex or glob; this folder, home, or everywhere; case, hidden files, app bundles, depth.
Search by meaning ⌃⌘F
Finds "financial results from the German branch" in a file that says "the Berlin office reported strong quarterly revenue". A document that uses your actual words still wins — meaning and literal matching are blended, and the file's own name counts. Text files and PDFs are read once; after that a query over a thousand passages takes well under a millisecond. Runs on macOS's own language model, on this machine, with nothing sent anywhere.
Search says what it skipped
Too large, not text, unreadable folder, result cap: each count is shown with the results.
Search ranking
Name matches outrank content matches; an exact name outranks a prefix, which outranks a substring.
.gitignore-aware search
Optional. Nested ignore files, negation and anchoring all honoured, and the count skipped is reported.
Saved searches
Named queries in the sidebar. Every option survives, and a search whose folder is gone runs in the current one.
In-folder filter /
Narrow the folder you are looking at without leaving it.
Command palette ⌘K
Fuzzy match over every command in the application.

Questions

Is it safe to open? It is not from the App Store.
It is signed with an Apple Developer ID and notarised by Apple, so it opens with a normal double-click and no warning. Notarising means Apple has scanned the build; it does not mean Apple endorses it.
Desktop, Documents and Downloads look empty.
Those folders are protected by macOS and need Full Disk Access. Soquel offers to set it up on the first launch, and the same window is under Soquel → Set Up Permissions… A file manager cannot grant itself that, and neither can anything else: the list is protected by System Integrity Protection precisely so no program can add itself to it.
Can Soquel replace Finder?
Not entirely, and no application can. macOS keeps folders for Finder — the call to reassign them is refused. Disks can be reassigned, so double-clicking one opens it here, and anything can be opened in Soquel through Open With.
Does it send anything anywhere?
No. Search by meaning runs on the language model macOS already ships, on your own machine. There is no account, no telemetry and no update check.
Where does it keep my settings?
Four readable JSON files in ~/Library/Application Support/Soquel/: settings, colours, saved layouts and the sidebar. Edit one in another editor while Soquel is running and the window redraws. Deleting the folder resets everything.
Is it really free?
Yes, MIT licensed, and nothing in it checks a licence. If it saved you something, the address is above.
