Questions

Is it safe to open? It is not from the App Store.
It is signed with an Apple Developer ID and notarised by Apple, so it opens with a normal double-click and no warning. Notarising means Apple has scanned the build; it does not mean Apple endorses it.
Desktop, Documents and Downloads look empty.
Those folders are protected by macOS and need Full Disk Access. Soquel offers to set it up on the first launch, and the same window is under Soquel → Set Up Permissions… A file manager cannot grant itself that, and neither can anything else: the list is protected by System Integrity Protection precisely so no program can add itself to it.
Can Soquel replace Finder?
Not entirely, and no application can. macOS keeps folders for Finder — the call to reassign them is refused. Disks can be reassigned, so double-clicking one opens it here, and anything can be opened in Soquel through Open With.
Does it send anything anywhere?
Not unless you switch one thing on. Search by meaning runs on the language model macOS already ships, on your own machine. There is no account and no telemetry, ever. The one exception is opt-in and off by default: Settings → Updates will ask github.com once a day for the latest release tag and compare it with your build. It sends nothing about you or your machine, and it never downloads or installs anything — it tells you, and the button opens the release page.
Where does it keep my settings?
Four readable JSON files in ~/Library/Application Support/Soquel/: settings, colours, saved layouts and the sidebar. Edit one in another editor while Soquel is running and the window redraws. Deleting the folder resets everything.
Is it really free?
Yes.
Where do I ask a question or report something?
Two places, pick whichever fits. soquel.hamlet.so is a forum — plain questions, "how do I", "this is behaving oddly", ideas. No GitHub account needed. GitHub issues is for bug reports with steps to reproduce, and feature requests you want tracked against the code.
